# Expense Tracker

A simple web-based expense tracker to add, view, and delete daily expenses. Built while learning full-stack web development from scratch.

## Features

- Add expenses with name and amount
- View total expenses automatically calculated
- Delete individual expenses
- Data saved permanently using localStorage (persists after refresh/close)

## Tech Stack

- HTML
- CSS
- JavaScript (DOM manipulation, localStorage)

## What I Learned

- Working with arrays and objects in JavaScript
- Using loops to render dynamic content
- Saving and retrieving data using localStorage
- Using Git and GitHub for version control
